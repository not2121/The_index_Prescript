# The Index Prescript Simulator

人差し指の指令をランダムに表示する、非公式のファンサイトです。

[サイトを開く](https://not2121.github.io/The_index_Prescript/)

## 遊び方

ヘルメスを押すと指令がクリック(またタップ)することで
指令が下されます。

指令は現在20種類です。
毎回ランダムに選ぶため、同じ指令が続くことがあります。
